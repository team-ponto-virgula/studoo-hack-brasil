## Percurso completo e resultados

![Fluxo aplicado em 12capturas reais](fluxo-completo-web.png)

[Verificações automatizadas e builds](verificacoes.json) · [Limites da prévia do app](rnweb-final-comprovado.json)

A web foi percorrida em 390×844 e 360×800. Os componentes React Native também foram executados, com a API mobile e o PostgreSQL locais; essa prova tem adaptadores de navegador e não equivale a aparelho ou TestFlight. A síntese do app declara a composição das rodadas e os ajustes no roteiro de teste.

A base de retenção já funciona: meta diária escolhida, primeira conclusão real, próxima lição, progresso salvo e retomada. Analytics D1/D7 e notificações são próximos trabalhos, ainda não implantados.
