Encontre o que importa

Uma consulta com foco.

O WHERE seleciona apenas os registros que atendem a uma condição. 

SELECT nome, cidade
FROM pessoas
WHERE cidade = 'Recife';

Aqui, aparecem somente as pessoas de Recife.
