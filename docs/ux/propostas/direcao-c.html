LIÇÃO 2 · WHERE · PRÉVIA

Encontre o que importa.

SELECT escolhe as colunas. WHERE define quais linhas entram no resultado.

SELECT nome FROM alunos
WHERE idade >= 18;

Aqui, aparecem apenas os nomes de quem tem 18 anos ou mais. Esta é uma amostra da próxima lição.
