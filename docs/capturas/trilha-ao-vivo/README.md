# Capturas da trilha gerada ao vivo (spec 03, web)

Prints da web tirados no navegador, com IA falsa e a conta sintética local. Estas imagens foram registradas para o PR e são mantidas aqui como documentação.

- `web-360/`: celular em 360×780 (escala 2), com toque. Inclui movimento reduzido, os erros e o caminho inteiro.
- `web-768/`: tablet em 768×1024.
- `web-1280/`: computador em 1280×800, com o foco do teclado e o caminho inteiro.
