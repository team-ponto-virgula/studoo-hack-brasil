# Capturas de todas as telas (web e app)

Prints da interface como está na `main` em 13/11/2026: entrada, apresentação, pedido, trilha gerada ao vivo, **Escrevendo suas lições**, aula por etapas, lição concluída, trilha e Meus planos. As animações (confete, Stu, trilha) foram capturadas no meio do movimento.

- `web-1440/`: web no computador em 1440×900, no navegador, com o servidor local, a IA falsa e a conta sintética local.
- `app-390/`: app no celular em 390×844 (escala 2), renderizado no navegador com React Native Web e a API simulada da prévia, que sempre devolve a trilha de SQL. Não são capturas de emulador ou aparelho Android; a aparência pode variar um pouco.

Os arquivos seguem a ordem do fluxo (`01-entrada.png`, `02-…`).
